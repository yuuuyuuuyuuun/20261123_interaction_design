# 世界は、わたしたちでできている

> “The best way to predict the future is to invent it.” — Alan Kay

教室の全員がスマホで同時に参加する、リアルタイムの予言ゲームです。

## ルール

| 要素 | 定義 |
|---|---|
| 世界 | 参加者数の16倍ほどの、上下左右がつながった長方形の盤面（最小96マス）。プレイヤーは散らばって1人1マス、残りは**群衆**（発明しない人々） |
| 同調 | 毎ターン、85%の確率で周り8マスを見て色を選び直す。色の引力は、周りにその色が n 人いるとき n³/(n³+2.35³)。**2〜3人いれば十分に惹かれ、それ以上はあまり変わらない**ので、3〜4人の小さな塊でも根付いて広がる。自分の今の色には少し留まる力（慣性0.4）がある |
| 気まぐれ | 毎ターン、0.8%の確率で周りに関係なくランダムな色になる |
| カリスマ | 毎ターン22%の確率で、**負けている色の発明者**の誰か1人に宿る。4〜6ターンの間、その人の周り7×7マスの人々が、毎ターンその色に強く惹かれる（引力+30）。大画面に名前が出て、本人のスマホにも表示される |
| ムーブメント | ラウンドの15%を過ぎると起こり始め（40%以降は毎ターン5%）、**負けている色**で小さな円（半径は盤面の短い辺の10〜18%）を一度に塗る |
| 静かな終盤 | ラウンドの最後の15%は、カリスマもムーブメントも新しく始まらない。見えている状況どおりに決着する |
| 未来 | ラウンド終了時に最も多い色（同数なら「未来は定まらなかった」） |
| 予言 | 色をタップ。何度でも変えられる。自分のマスは流され続ける |
| 発明 | 色をタップ。取り消せない。自分のマスはその色で固定され、同調・気まぐれ・カリスマ・ムーブメントのどれにも影響されない |
| 得点 | 未来を当てたら「最後に宣言した時点の残りターン数」。外れたら0 |

発明に特別な有利・不利はありません。発明者は**柔軟性**（乗り換えの自由）を捨て、**影響力**を得ます。

## 起動

```bash
npm install
npm start
```

起動するとコンソールに2つのURLが表示されます。

- 参加者用 `http://<host>:3000/` — 大画面のQRコードからも開けます
- 大画面用 `http://<host>:3000/host?key=<HOST_KEY>` — 進行操作ができるのはこのURLだけです

大画面の右側で、ラウンド数・1ラウンドのターン数・**ボットの種類ごとの人数**を設定できます（ロビーとラウンドの合間）。ボットは人間と同じく盤面の1マスになり、ランキングにも載ります。

| ボット | 動き |
|---|---|
| 期待値予言 | 勝率×得点で判断する。乗り換えると得点がリセットされるので、少し不利になっても粘ることがある |
| 追従予言 | 多数派を予言し、多数派が入れ替わるたびに乗り換える |
| 気まぐれ予言 | 好きな色を予言し、ときどき気が変わる |
| 早期発明 | 開始直後に、勝ちそうな色を発明する |
| 地元発明 | 自分の周りに仲間が3人以上いる色を、その場で発明する |
| 機を見て発明 | 予言で様子を見て、途中で勝ちそうな色を発明する |
| 勝ち馬発明 | 予言で様子を見て、勝ちがほぼ確実（勝率85%以上）になった色を発明する |
| 逆張り発明 | 開始直後に、最も少ない色を発明する |

ボットは人間並みに1〜3ターン遅れて動き始めます。「勝ちそうな色」は、盤面から各色の勝率を見積もるモデル（`src/odds.js`）で判断します。このモデルは、盤面で誰にでも見える3つの情報（色の割合・発明者の割合・カリスマの範囲）から、残りターン数ごとに学習した重みで勝率を計算します。法則を変えたら `node sim/fit-odds.js` で学習し直してください。

環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `HOST_KEY` | 起動ごとにランダム | 大画面用URLの鍵 |
| `TICK_MS` | 1000 | 1ターンの長さ（ミリ秒） |
| `OBSERVE_MS` | 5000 | 各ラウンド開始前の観察時間 |

## 開発用

```bash
npm test                         # エンジンのテスト
node sim/simulate.js             # 既定値でのバランス報告（塊の定着率・盤面・逆転率・トーナメント）
node sim/tournament.js 300       # 5ラウンド制ゲームを300回行い、戦略ごとの優勝率を出す
node sim/nucleation.js           # 塊の定着率だけを見る
node sim/search.js 36            # 目標をまとめた評価関数でパラメータをランダム探索
node sim/fit-odds.js             # ボットの勝率モデルを学習し直す
node test/bots.js 20             # 本物のソケット接続でボットを20人つなぐ（負荷テスト用）
```

ボットの判断ロジック（`src/bots.js`）は、シミュレーションと実際のゲームで同じものを使っています。

## シミュレーションで決めたこと

`sim/` のスクリプトで、ボット同士に対戦させて法則を選びました（30人・3色・60ターン）。

### 経緯
1. **最初の盤面（参加者だけ・隣1人を真似る）**：盤面が小さく、ほとんど変化しませんでした。1人の発明が強すぎました。
2. **盤面を大きくし、群衆・気まぐれ・ムーブメントを追加し、「近くの3人を見て多い色に合わせる」に**：盤面は活発になりました。しかし、発明者6人の塊でも敵陣では領域にならず（定着率ほぼ0%）、少数派を選ぶと何も起こりませんでした。序盤に決まった勢力図も動きませんでした。
3. **ムーブメントを「育つ波」にした版（不採用）**：巨大な円が何ターンも居座って機械的に塗り広げるだけで、プレイヤーの選択と無関係でした。
4. **今の形**
   - **同調**：引力が2〜3人で頭打ちになる形にしました。発明者3〜4人の塊が、敵陣でも領域として根付くようになりました。
     - 「3〜4人で引力が最大になり、それ以上は下がる」形も試しました。大きな領域がすべて細切れのモザイクになったので、頭打ちにとどめています。
   - **ムーブメント**：一度に塗る旧方式に戻しました。負けている色だけ・小さく・まれにしています。
   - **カリスマ**：少数派の発明者に逆転の主役になる機会を与えます。
   - **静かな終盤**：終盤は新しい出来事が起きないようにしました。

### 既定値での結果

**塊の定着率**（敵の色一色の中に塊を置き、20ターン後に領域（9×9マス中20マス以上）ができた割合）

| 塊の大きさ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 流されるマスだけ | 1% | 2% | 3% | 5% | 6% | 7% |
| 中心の1人が発明者 | 8% | 12% | 14% | 15% | 17% | 21% |
| 全員が発明者 | 8% | 32% | 49% | 56% | 78% | 83% |

（旧来の「近くの3人を見て多い色」の法則では、どの行もほぼ0%でした）

**盤面**（誰も発明しない世界、30人）：1ターンに29%のマスが変化します。一色の世界も、60ターンで8%しか侵食されません。偶然の塊はほとんど育たないためです。

**逆転**（誰も発明しない世界）

| 人数 | 盤面 | 多数派の交代（回/ラウンド） | 3ターン時点の多数派が負ける率 | 30ターン | 50ターン | 55ターン |
|---|---|---|---|---|---|---|
| 10 | 15×11 | 4.7 | 51% | 31% | 17% | 11% |
| 20 | 21×15 | 5.1 | 51% | 35% | 16% | 15% |
| 30 | 25×19 | 5.6 | 58% | 32% | 18% | 13% |
| 40 | 29×22 | 5.0 | 51% | 29% | 17% | 13% |

- 8種類のボットが均等にいるラウンドで、開始4ターン時点の多数派が最終的に勝つ率は52%です。
- 終盤の逆転のうち、その時点以降に新しく始まった出来事が原因のもの：50ターン以降で3%、55ターン以降で0%。
- 全員が開始直後に同じ色を発明すると、ほぼ必ず勝ちます（全員が同じ点になるので、必勝法にはなりません）。

**トーナメント**（30人・5ラウンド・300ゲーム。優勝指数1.00＝人数の割合どおりに優勝する）

| 戦略 | 1ラウンド平均点（均等構成 / ランダム構成） | 優勝指数（均等構成 / ランダム構成） |
|---|---|---|
| 早期発明 | 41.3 / 46.3 | 3.26 / 2.57 |
| 期待値予言 | 43.9 / 46.5 | 1.89 / 1.23 |
| 地元発明 | 27.4 / 25.5 | 1.59 / 1.56 |
| 逆張り発明 | 20.0 / 34.0 | 0.99 / 2.52 |
| 機を見て発明 | 29.0 / 33.0 | 0.03 / 0.00 |
| 追従予言 | 19.2 / 28.3 | 0.00 / 0.21 |
| 勝ち馬発明 | 22.5 / 30.4 | 0.00 / 0.03 |
| 気まぐれ予言 | 8.8 / 8.7 | 0.00 / 0.03 |

- 平均点が最も高いのは期待値予言です。
- 優勝は、序盤に決め打ちする4つの戦略（早期発明・期待値予言・地元発明・逆張り発明）で分け合っています。
- 様子を見てから動く戦略は、平均点はそこそこでも優勝できません。得点が「宣言時点の残りターン数」なので、30人の中で1位になるには、序盤から当て続ける必要があるからです。
