# 世界は、わたしたちでできている

> “The best way to predict the future is to invent it.” — Alan Kay

教室の全員がスマホで同時に参加する、リアルタイムの予言ゲームです。

## ルール

| 要素 | 定義 |
|---|---|
| 世界 | 参加者数の16倍ほどの、上下左右がつながった長方形の盤面（最小96マス）。プレイヤーは散らばって1人1マス、残りは**群衆**（発明しない人々）。各ラウンドは**3色ちょうど同数**のばらばらな状態から始まる（未来は白紙） |
| 同調 | 毎ターン、81%の確率で色を考え直す。周り8人はそれぞれ77%の確率で自分の色を口にし、自分の今の色も1票と数える。**2票以上集まった色が「あり得る選択肢」**になり、その中から五分五分で1つを選ぶ（選択肢がなければ今の色のまま）。1〜2マスの孤立した色は2票集まらず消えるが、3〜4マスの塊なら仲間の声が届いて残りやすい。大きな領域の内側には他の色の声が届かないので、大きな領域ほど壊れにくい |
| 気まぐれ | 毎ターン、0.6%の確率で周りに関係なくランダムな色になる |
| カリスマ | 毎ターン20%の確率で、**負けている色の発明者**の誰か1人に宿る。5〜8ターンの間、その人を中心とする円（盤面の16%）の人々は、毎ターン50%の確率でその色になる。大画面に名前が出て、本人のスマホにも表示される。発明した人だけが起点になれるので、劣勢の色を発明した人には巻き返しの主役になる可能性がある |
| ムーブメント | ラウンドの15%を過ぎると起こり始め（40%以降も毎ターン3%とまれ）、**負けている色**で盤面の25〜50%を覆う大きな円を一度に塗る |
| 静かな終盤 | ラウンドの最後の15%は、カリスマもムーブメントも新しく始まらない。見えている状況どおりに決着する |
| 未来 | ラウンド終了時に最も多い色（同数なら「未来は定まらなかった」） |
| 予言 | 色をタップ。何度でも変えられる。自分のマスは流され続ける |
| 発明 | 色をタップ。取り消せない。自分のマスはその色で固定され、同調・気まぐれ・カリスマ・ムーブメントのどれにも影響されない |
| 得点 | 未来を当てたら「最後に宣言した時点の残りターン数」。外れたら0 |

発明に特別な有利・不利はありません。発明者は**柔軟性**（乗り換えの自由）を捨て、**影響力**を得ます。

## 起動

```bash
npm install
npm start
```

起動するとコンソールに2つのURLが表示されます。

- 参加者用 `http://<host>:3000/` — 大画面のQRコードからも開けます
- 大画面用 `http://<host>:3000/host?key=<HOST_KEY>` — 進行操作ができるのはこのURLだけです

大画面の右側で、ラウンド数・1ラウンドのターン数・**ボットの種類ごとの人数**を設定できます（ロビーとラウンドの合間）。ボットは人間と同じく盤面の1マスになり、ランキングにも載ります。

| ボット | 動き |
|---|---|
| 期待値予言 | 勝率×得点で判断する。乗り換えると得点がリセットされるので、少し不利になっても粘ることがある |
| 追従予言 | 多数派を予言し、多数派が入れ替わるたびに乗り換える |
| 予言→発明 | 勝ちそうな色がはっきりしていれば（勝率55%以上）最初から発明し、そうでなければ予言する。乗り換えるときは発明で乗り換える |
| 気まぐれ予言 | 好きな色を予言し、ときどき気が変わる |
| 早期発明 | 開始直後に、勝ちそうな色を発明する |
| 地元発明 | 自分の周りに仲間が3人以上いる色を、その場で発明する |
| 機を見て発明 | 何も宣言せずに様子を見て、途中で勝ちそうな色を発明する |
| 勝ち馬発明 | 何も宣言せずに様子を見て、勝率が60%を超えた色を発明する |
| 逆張り発明 | 開始直後に、最も少ない色を発明する |

ボットは人間並みに1〜3ターン遅れて動き始めます。様子見型の発明ボットは、発明するまで何も宣言しません（ルール上、発明は新しい宣言なので、先に予言していても得点はリセットされるため）。期待値予言は、勝率を正しく見積もって最適に動く「上手なプレイヤー」の目安です。「勝ちそうな色」は、盤面から各色の勝率を見積もるモデル（`src/odds.js`）で判断します。このモデルは、盤面で誰にでも見える3つの情報（色の割合・発明者の割合・カリスマの範囲）から、残りターン数ごとに学習した重みで勝率を計算します。法則を変えたら `node sim/fit-odds.js` で学習し直してください。

環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `HOST_KEY` | 起動ごとにランダム | 大画面用URLの鍵 |
| `TICK_MS` | 1000 | 1ターンの長さ（ミリ秒） |
| `OBSERVE_MS` | 5000 | 各ラウンド開始前の観察時間 |

## 開発用

```bash
npm test                         # エンジンのテスト
node sim/simulate.js             # 既定値でのバランス報告（塊の定着率・盤面・逆転率・トーナメント）
node sim/tournament.js 300       # 5ラウンド制ゲームを300回行い、戦略ごとの平均順位を出す
node sim/rankspread.js           # （モジュール）平均順位のばらつきで設定を比べる
node sim/meta.js                 # 理屈のある戦略どうし（待つ発明・予言・混成）の駆け引きを、構成を変えて比べる
OPTS='{"balancedStart":true}' node sim/meta.js   # 法則を変えて比べる（勝率モデルは FIT_OPTS/OUT と ODDS_MODEL で差し替え）
node sim/nucleation.js           # 塊の定着率だけを見る
node sim/search.js 36            # 目標をまとめた評価関数でパラメータをランダム探索
node sim/fit-odds.js             # ボットの勝率モデルを学習し直す
node test/bots.js 20             # 本物のソケット接続でボットを20人つなぐ（負荷テスト用）
```

ボットの判断ロジック（`src/bots.js`）は、シミュレーションと実際のゲームで同じものを使っています。

## シミュレーションで決めたこと

`sim/` のスクリプトで、ボット同士に対戦させて法則を選びました（30人・3色・60ターン）。

### 経緯
1. **最初の盤面（参加者だけ・隣1人を真似る）**：盤面が小さく、ほとんど変化しませんでした。1人の発明が強すぎました。
2. **盤面を大きくし、群衆・気まぐれ・ムーブメントを追加し、「近くの3人を見て多い色に合わせる」に**：盤面は活発になりました。しかし、発明者6人の塊でも敵陣では領域にならず（定着率ほぼ0%）、少数派を選ぶと何も起こりませんでした。序盤に決まった勢力図も動きませんでした。
3. **ムーブメントを「育つ波」にした版（不採用）**：巨大な円が何ターンも居座って機械的に塗り広げるだけで、プレイヤーの選択と無関係でした。
4. **「引力が2〜3人で頭打ち」の関数（飽和型）**：狙いどおりの性質は出ましたが、引力の形を人工的に決めていました。
5. **今の形：「声」の同調**
   - 周りの人の声がランダムに届き、2票以上集まった色が選択肢になる、というサンプリングだけで同じ性質を出しています。
   - 1〜2マスは消え、3〜4マス以上の塊（発明者がいるか、偶然が重なってできたもの）が残って広がる可能性を持ちます。
   - 大きな領域ほど壊れにくいという原則は保っています。
   - 試して採用しなかった法則：
     - 決まった人数を見て「何割が同じ色か」で決める法則：どれも、小さな塊のマスが常に少数派になって飲み込まれました。
     - 「味方が1人でもいれば留まる」法則：小さな塊は残りますが、盤面全体が固まりました。
     - 「3〜4人で引力が最大、それ以上は下がる」形：盤面全体が細切れのモザイクになりました。
   - **ムーブメント**：一度に塗る旧方式に戻しました。負けている色だけに起き、盤面の25〜50%を一色に塗ります（まれな大事件）。
   - **カリスマ**：少数派の発明者に逆転の主役になる機会を与えます。
   - **大きさの決め方**：カリスマ・ムーブメントの大きさは盤面に対する割合で決めているので、人数が変わっても比率は一定です。
   - **静かな終盤**：終盤は新しい出来事が起きないようにしました。
6. **3色同数で開始し、カリスマを主役に**
   - 開始時に「一番多い色」という目印があると、全員がそこへ集まって結果が決まってしまいます。そのため、3色同数で始めるようにしました。
   - 発明者だけが起点になれるカリスマを大きく（盤面の16%）し、誰にでも起きるムーブメントをまれ（毎ターン3%）にしました。盤面を動かすのは主に人の選択になり、発明することの意味が大きくなります。

### 既定値での結果

**塊の行方**（敵の色一色の中に赤の塊を置いて20ターン後）

| 塊の大きさ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 残る率：流されるマスだけ | — | 10% | 15% | 24% | 22% | 30% |
| 残る率：中心の1人が発明者 | — | 63% | 68% | 72% | 71% | 73% |
| 領域になる率（9×9中20マス以上）：流されるマスだけ | 0% | 1% | 4% | 5% | 4% | 7% |
| 領域になる率：中心の1人が発明者 | 1% | 8% | 8% | 15% | 18% | 21% |
| 領域になる率：全員が発明者 | 1% | 27% | 49% | 62% | 74% | 86% |

- 1マスの「残る率」は、気まぐれで偶然生まれる赤と区別できないので省いています。
- 旧来の「近くの3人を見て多い色」の法則では、領域になる率はどの行もほぼ0%でした。

**盤面**（誰も発明しない世界、30人）

- 1ターンに31%のマスが変化します。
- 一色の世界でも、60ターンで侵食されるのは1%だけです（気まぐれでは崩れません）。

**逆転**（誰も発明しない世界）

| 人数 | 盤面 | 多数派の交代（回/ラウンド） | 3ターン時点の多数派が負ける率 | 30ターン | 50ターン | 55ターン | 全員一斉発明の成功率 |
|---|---|---|---|---|---|---|---|
| 10 | 15×11 | 6.1 | 57% | 43% | 21% | 16% | 89% |
| 20 | 21×15 | 5.2 | 62% | 49% | 13% | 8% | 88% |
| 30 | 25×19 | 5.9 | 63% | 47% | 15% | 5% | 83% |
| 40 | 29×22 | 5.2 | 61% | 51% | 9% | 5% | 80% |

- 全種類のボットが均等にいるラウンドで、開始4ターン時点の多数派が最終的に勝つ率は47%です。
- 終盤の逆転のうち、その時点以降に新しく始まった出来事が原因のもの：50ターン以降で7%（51ターン目までは起こりうるため）、55ターン以降で0%。

**トーナメント**（30人・5ラウンド・300ゲーム。平均順位は30人中、小さいほど強い）

| 逆張り発明 | 14.6 / 13.8 | 29.7 / 34.1 | 2.57 / 2.46 |
| 地元発明 | 17.0 / 17.7 | 26.0 / 25.5 | 1.59 / 1.50 |

- 優勝（1位）は、序盤に発明で決め打ちする振れ幅の大きい戦略（逆張り・早期・地元）もよく取ります。

### 理屈のある戦略どうしの駆け引き（`sim/meta.js`）

理屈のある戦略だけの集団で、構成を変えて平均順位（30人中）を比べました。

- 発明：0〜6ターン待ってから、勝ちそうな色を発明する
- 予言：乗り換えの慎重さを変える
- 混成：予言で始め、乗り換えるときは発明する。はっきりしていれば最初から発明する

| 設定 | 予言（最良） | 混成（最良） | 発明（すぐ） |
|---|---|---|---|
| ランダムな盤面で開始・カリスマ5%・ムーブメント12% | 7.8〜10.0 | 10.2〜16.2 | 18.3〜22.0 |
| 3色同数で開始・カリスマ5%・ムーブメント12% | 8.7〜9.7 | 9.6〜15.3 | 16.6〜21.5 |
| **3色同数で開始・カリスマ16%（20%/ターン）・ムーブメント3%（今の既定）** | **10.7〜12.6** | **10.5〜13.5** | **14.5〜16.6** |

（範囲は、発明/予言/混成の人数構成を10/10/10・4/6/20・16/6/8・6/16/8と変えたときの平均順位）

- 以前の設定では予言が一方的に有利でした。発明の効果は同じ色を選んだ全員の得になるので、予言者がただ乗りできたためです。
- 開始時の目印（最初から多い色）をなくし、発明者だけが起点になれるカリスマを主役にすると、予言・混成・発明が拮抗します。混成が予言を上回る構成もあります。
- 何も宣言せずに待つ純粋な発明が不利なのは当然です（0ターン目に予言しておくことは、何もしないことの完全上位互換）。実際の「待ち」は、予言しておいてどこで発明に切り替えるかという形で表れます。
