# 世界は、わたしたちでできている

> “The best way to predict the future is to invent it.” — Alan Kay

教室の全員がスマホで同時に参加する、リアルタイムの予言ゲームです。

## ルール

| 要素 | 定義 |
|---|---|
| 世界 | 参加者全員。1人が1マス。マスは3色（赤・青・黄）のどれか |
| 法則 | 模倣：マスは時々、隣（8近傍）の誰か1人の色を真似る |
| 未来 | ラウンド終了時に最も多い色（同数なら「未来は定まらなかった」） |
| 予言 | 色をタップ。何度でも変えられる。自分のマスは法則に流され続ける |
| 発明 | 長押し。取り消せない。自分のマスはその色で固定され、周りに影響を与え続ける |
| 得点 | 未来を当てたら「最後に宣言した時点の残り秒数」。外れたら0 |

発明に特別な有利・不利はありません。発明者は**柔軟性**（乗り換えの自由）を捨て、**影響力**を得ます。

## 起動

```bash
npm install
npm start
```

起動するとコンソールに2つのURLが表示されます。

- 参加者用 `http://<host>:3000/` — 大画面のQRコードからも開けます
- 大画面用 `http://<host>:3000/host?key=<HOST_KEY>` — 進行操作ができるのはこのURLだけです

環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `HOST_KEY` | 起動ごとにランダム | 大画面用URLの鍵 |
| `TICK_MS` | 1000 | 世界が1回更新される間隔 |
| `OBSERVE_MS` | 5000 | 各ラウンド開始前の観察時間 |

ラウンド数（既定5）と1ラウンドの長さ（既定60秒）は大画面のロビーで変えられます。

## 開発用

```bash
npm test                  # エンジンのテスト
npm run sim               # バランスのシミュレーション
node test/bots.js 20      # ボット20人を参加させる
```

## シミュレーションで決めたこと

`sim/` のスクリプトで、ボット同士の対戦を数千ラウンド回して法則を選びました（30人・3色・60秒）。

1. **当初案の「決定的な多数決」は不採用。**世界が約4秒で固まり、開始時の多数派がそのまま未来になる確率が80%でした。「最初の多数派に乗るだけの予言」が満点近くを取ってしまいます。
2. **「模倣（ボーターモデル）」を採用。**誰も発明しないとき、開始時の多数派が未来になるのは約40%です。予言は本当に難しくなります。
3. **予言と発明は拮抗する。**発明者が少ないと発明が得で、多いと予言が得になります（30人での平均得点）。

   | 発明者の割合 | 予言者 | 発明者 |
   |---|---|---|
   | 10% | 35.1 | 38.4 |
   | 20% | 39.4 | 40.1 |
   | 30% | 42.4 | 41.2 |
   | 50% | 47.0 | 42.8 |

4. **更新の頻度は人数に比例させる（N/100）。**こうすると、8〜60人のどの人数でも、ほかに誰も発明しないときの単独の発明の成功率が約60〜67%になります（ランダムな予言なら33%）。人数が変わっても、1人が世界を動かせる手応えはほぼ同じです。
