# 世界は、わたしたちでできている

> “The best way to predict the future is to invent it.” — Alan Kay

教室の全員がスマホで同時に参加する、リアルタイムの予言ゲームです。

## ルール

| 要素 | 定義 |
|---|---|
| 世界 | 参加者数の16倍ほどの、上下左右がつながった長方形の盤面（最小96マス）。プレイヤーは散らばって1人1マス、残りは**群衆**（発明しない人々） |
| 同調 | 毎ターン、80%の確率で**近くの3人を見て、多い色に合わせる** |
| 気まぐれ | 毎ターン、4%の確率で周りに関係なくランダムな色になる |
| ムーブメント | ラウンドの15%を過ぎると起こり始め（50%以降は毎ターン8%）、**負けている色**の支持者を中心に熱狂の波が1ターン0.45マスずつ広がる。波が届いたマスはその色になり、3〜5ターン立ち止まる。**差をつけられている色ほど大きく育つ**（揺り戻し。最大で盤面の短い辺の42%の半径）。最終的な大きさは点線の円で見える |
| 未来 | ラウンド終了時に最も多い色（同数なら「未来は定まらなかった」） |
| 予言 | 色をタップ。何度でも変えられる。自分のマスは流され続ける |
| 発明 | 色をタップ。取り消せない。自分のマスはその色で固定され、同調・気まぐれ・ムーブメントのどれにも影響されない |
| 得点 | 未来を当てたら「最後に宣言した時点の残りターン数」。外れたら0 |

発明に特別な有利・不利はありません。発明者は**柔軟性**（乗り換えの自由）を捨て、**影響力**を得ます。

## 起動

```bash
npm install
npm start
```

起動するとコンソールに2つのURLが表示されます。

- 参加者用 `http://<host>:3000/` — 大画面のQRコードからも開けます
- 大画面用 `http://<host>:3000/host?key=<HOST_KEY>` — 進行操作ができるのはこのURLだけです

大画面の右側で、ラウンド数・1ラウンドのターン数・**ボットの種類ごとの人数**を設定できます（ロビーとラウンドの合間）。ボットは人間と同じく盤面の1マスになり、ランキングにも載ります。

| ボット | 動き |
|---|---|
| 期待値予言 | 勝率×得点で判断する。乗り換えると得点がリセットされるので、少し不利になっても粘ることがある |
| 早期発明 | 開始直後に、勝ちそうな色を発明する |
| 機を見て発明 | 期待値予言で様子を見て、途中で勝ちそうな色を発明する |
| 逆張り発明 | 開始直後に、最も少ない色を発明する |

ボットは人間並みに1〜3ターン遅れて動き始めます。「勝ちそうな色」は、盤面から各色の勝率を見積もるモデル（`src/odds.js`）で判断します。このモデルは、盤面で誰にでも見える3つの情報（色の割合・発明者の割合・育ちきっていない波の大きさ）から、残りターン数ごとに学習した重みで勝率を計算します。法則を変えたら `node sim/fit-odds.js` で学習し直してください。

期待値予言は、今の予言を続けたときの期待値「勝率 ×（予言した時点の残りターン）」と、乗り換えたときの期待値「勝率 × 今の残りターン」を比べます。乗り換えの方が1割以上高い状態が続いたときだけ乗り換えます。

環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `HOST_KEY` | 起動ごとにランダム | 大画面用URLの鍵 |
| `TICK_MS` | 1000 | 1ターンの長さ（ミリ秒） |
| `OBSERVE_MS` | 5000 | 各ラウンド開始前の観察時間 |

## 開発用

```bash
npm test                         # エンジンのテスト
node sim/simulate.js             # 既定値でのバランス報告
node sim/explore.js              # パラメータの探索（そのときどきの検討用）
node sim/fit-odds.js             # ボットの勝率モデルを学習し直す
node test/bots.js 20             # 本物のソケット接続でボットを20人つなぐ（負荷テスト用）
```

ボットの判断ロジック（`src/bots.js`）は、シミュレーションと実際のゲームで同じものを使っています。

## シミュレーションで決めたこと

`sim/` のスクリプトで、ボット同士に数千ラウンド対戦させて法則を選びました（30人・3色・60ターン）。

### 経緯
1. **最初の盤面（参加者だけ・隣1人を真似る）**：盤面が小さく、ほとんど変化しませんでした。1人の発明が強すぎました。
2. **盤面を大きくし、群衆・気まぐれ・ムーブメントを追加**：盤面は活発になりました。しかし「隣1人を真似る」法則のままでは、全員が同じ色を発明するとほぼ100%勝ちます。
3. **「近くの3人を見て多い色に合わせる」に変更**：散らばった発明者は、周りの多数派に打ち消されるようになりました。
4. **ムーブメントを「一色に塗る」から「劣勢な色の熱狂が育つ波」へ**：旧方式では最大で盤面の6割が一瞬で塗り替わり、終了直前の1回で勝敗が決まることがありました。新方式では、逆転の起こりやすさと「全員一斉発明」の成功率を旧方式とほぼ同じに保ったまま、終盤に新しく始まったムーブメントによる逆転を大きく減らしました。
   - 劣勢な色にだけ起こる：勝っている色のムーブメントにはゲーム上の意味がないため。
   - 序盤は起こらない：逆転要素は、不利な色を選んだ人に希望を残すためのものなので。
   - 波は少しずつ育つ：終了直前に始まった波は小さいまま終わります。最終的な大きさも点線の円で見えるので、プレイヤーは対応できます。
   - 差をつけられている色ほど大きく育つ（揺り戻し）：小さな波だけでは、大勢の発明者に支えられた大差は覆せないため。

### 既定値での結果

| 人数 | 盤面 | 1ターンに変化するマス | 多数派の交代（回/ラウンド） | 30ターン時点の多数派が負ける率 | 50ターン時点 | 55ターン時点 | 1人だけの発明の成功率 | 全員一斉に発明したときの成功率 |
|---|---|---|---|---|---|---|---|---|
| 5 | 11×9 | 20% | 4.2 | 66% | 41% | 29% | 35% | 59% |
| 10 | 15×11 | 20% | 3.6 | 58% | 36% | 25% | 38% | 84% |
| 20 | 21×15 | 20% | 3.7 | 55% | 31% | 21% | 38% | 88% |
| 30 | 25×19 | 20% | 3.3 | 52% | 29% | 19% | 35% | 83% |
| 40 | 29×22 | 20% | 3.2 | 45% | 22% | 15% | 33% | 83% |

- 「多数派が負ける率」と「1人だけの発明の成功率」は、誰も発明しない（またはその1人だけが発明する）場合の値です。当てずっぽうなら33%です。
- **終盤のムーブメントが原因の逆転**（30人。同じラウンドを、終盤に新しいムーブメントが起きない条件でやり直して比較）

  | | 旧方式 | 新方式 |
  |---|---|---|
  | 50ターン時点の多数派が負ける率 | 23% | 26% |
  | 　うち50ターン以降に始まったムーブメントが原因 | 15% | 3% |
  | 55ターン時点の多数派が負ける率 | 15% | 17% |
  | 　うち55ターン以降に始まったムーブメントが原因 | 10% | 1% |

- **平均得点**（30人、満点60）
  - 発明者が多い集団（早期発明70%・期待値予言30%）：発明43.1、予言43.0
  - 発明者が少ない集団（早期発明10%・期待値予言90%）：発明29.0、予言30.1
  - 4種類が均等に混ざった集団：期待値予言38.7、早期発明34.8、機を見て発明25.0、逆張り発明24.8
  - 予言ボットの比較（同じ世界で対戦）：期待値予言31.9、旧来の「多数派が入れ替わるたびに乗り換える」予言26.9
- **勝率モデルから分かること**：残りが多い序盤は、色の割合よりも「その色の発明者の割合」が勝敗をよく予測します（重みは割合の約20〜50倍）。終盤になると、割合が支配的になります。
