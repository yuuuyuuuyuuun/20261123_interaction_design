# 世界は、わたしたちでできている

> “The best way to predict the future is to invent it.” — Alan Kay

教室の全員がスマホで同時に参加する、リアルタイムの予言ゲームです。

## ルール

| 要素 | 定義 |
|---|---|
| 世界 | 参加者数の16倍ほどの、上下左右がつながった長方形の盤面（最小96マス）。プレイヤーは散らばって1人1マス、残りは**群衆**（発明しない人々） |
| 同調 | 毎ターン、80%の確率で**近くの3人を見て、多い色に合わせる** |
| 気まぐれ | 毎ターン、4%の確率で周りに関係なくランダムな色になる |
| ムーブメント | 毎ターン12%の確率で、盤面の一帯（盤面の短い辺の22〜45%の半径の円）が一色に染まる（流行・災害） |
| 未来 | ラウンド終了時に最も多い色（同数なら「未来は定まらなかった」） |
| 予言 | 色をタップ。何度でも変えられる。自分のマスは流され続ける |
| 発明 | 色をタップ。取り消せない。自分のマスはその色で固定され、同調・気まぐれ・ムーブメントのどれにも影響されない |
| 得点 | 未来を当てたら「最後に宣言した時点の残りターン数」。外れたら0 |

発明に特別な有利・不利はありません。発明者は**柔軟性**（乗り換えの自由）を捨て、**影響力**を得ます。

## 起動

```bash
npm install
npm start
```

起動するとコンソールに2つのURLが表示されます。

- 参加者用 `http://<host>:3000/` — 大画面のQRコードからも開けます
- 大画面用 `http://<host>:3000/host?key=<HOST_KEY>` — 進行操作ができるのはこのURLだけです

大画面の右側で、ラウンド数・1ラウンドのターン数・**ボットの種類ごとの人数**を設定できます（ロビーとラウンドの合間）。ボットは人間と同じく盤面の1マスになり、ランキングにも載ります。

| ボット | 動き |
|---|---|
| 追従予言 | すぐ多数派を予言し、多数派が入れ替わると乗り換える |
| 様子見予言 | しばらく様子を見てから多数派を予言し、以後は乗り換える |
| 早期発明 | 開始直後に多数派を発明する |
| 機を見て発明 | 予言で様子を見て、途中で多数派を発明する |
| 逆張り発明 | 開始直後に最も少ない色を発明する |

ボットは人間並みに1〜3ターン遅れて反応し、多数派が入れ替わっても2〜4ターン続くまで乗り換えません。

環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `HOST_KEY` | 起動ごとにランダム | 大画面用URLの鍵 |
| `TICK_MS` | 1000 | 1ターンの長さ（ミリ秒） |
| `OBSERVE_MS` | 5000 | 各ラウンド開始前の観察時間 |

## 開発用

```bash
npm test                         # エンジンのテスト
node sim/simulate.js             # 既定値でのバランス報告
node sim/explore.js              # パラメータの総当たり探索
node test/bots.js 20             # 本物のソケット接続でボットを20人つなぐ（負荷テスト用）
```

ボットの判断ロジック（`src/bots.js`）は、シミュレーションと実際のゲームで同じものを使っています。

## シミュレーションで決めたこと

`sim/` のスクリプトで、ボット同士に数千ラウンド対戦させて法則を選びました（30人・3色・60ターン）。

### 経緯
1. **最初の盤面（参加者だけ・隣1人を真似る）**：盤面が小さく、ほとんど変化しませんでした。1人の発明が強すぎ、全員が開始直後に多数派を発明すると勝負が決まっていました。
2. **盤面を大きくし、群衆・気まぐれ・ムーブメントを追加**：盤面は活発になりました。しかし「隣1人を真似る」法則のままでは、全員が同じ色を発明するとほぼ100%勝ちます。動かない発明者の影響が、時間とともに際限なく広がるためです。
3. **「近くの3人を見て多い色に合わせる」に変更**：散らばった発明者は、周りの多数派に打ち消されるようになりました。発明が効くのは、場所と仲間がそろったときです。
4. **ムーブメントを大きくし、盤面を16倍に**：多数派に合わせる法則は序盤の多数派を雪だるま式に伸ばしますが、大きなムーブメントで覆るようになりました。

### 既定値での結果

| 人数 | 盤面 | 1ターンに変化するマス | 多数派の交代（回/ラウンド） | 3ターン時点の多数派が勝つ率 | 50ターン時点の多数派が勝つ率 | 1人だけの発明の成功率 | 全員一斉に発明したときの成功率 |
|---|---|---|---|---|---|---|---|
| 5 | 11×9 | 21% | 3.8 | 43% | 79% | 43% | 76% |
| 10 | 15×11 | 21% | 4.0 | 48% | 77% | 43% | 87% |
| 20 | 21×15 | 20% | 4.1 | 40% | 76% | 38% | 85% |
| 30 | 25×19 | 20% | 4.2 | 35% | 75% | 36% | 84% |
| 40 | 29×22 | 19% | 4.2 | 40% | 70% | 32% | 82% |

- 「多数派が勝つ率」と「1人だけの発明の成功率」は、誰も発明しない（またはその1人だけが発明する）場合の値です。当てずっぽうなら33%です。
- 5種類のボットが均等に混ざった集団（30人）での平均得点（満点60）は、追従予言22.9、早期発明23.7、様子見予言19.7、機を見て発明19.9、逆張り発明19.4でした。どれも飛び抜けていません。
